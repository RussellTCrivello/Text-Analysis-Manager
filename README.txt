Thank you for installing Text Analysis Manager!

DESCRIPTION
-----------
Text Analysis Manager is a comprehensive tool for organizing, analyzing, 
and reporting research data. It provides an intuitive interface for managing 
research sources, content, and analysis with powerful export capabilities.

FEATURES
--------
* Source Management - Organize and track research sources
* Content Management - Store and categorize research content
* Content Analysis - Analyze and link related content
* Comprehensive Reports - Generate detailed reports and statistics
* Multi-format Export - Export to Word, Excel, PDF, and more
* Bilingual Support - Full English and Arabic interface
* Print Support - Professional print layouts with customizable headers
* Backup & Restore - Protect your data with automated backups
* Attachment Management - Associate files with your research records

SYSTEM REQUIREMENTS
-------------------
* Operating System: Windows 7 or later (64-bit recommended)
* Memory: 4 GB RAM minimum (8 GB recommended)
* Storage: 200 MB for installation + space for your data
* Display: 1280x720 minimum resolution

GETTING STARTED
---------------
1. Launch the application from the Start Menu or Desktop shortcut
2. The application will create a local database on first run
3. Start by adding sources in the "Sources" tab
4. Add content linked to your sources in the "Contents" tab
5. Use the "Analysis" tab for deeper content analysis
6. Generate reports in the "Reports" tab

DATA LOCATION
-------------
Your data is stored in:
  %APPDATA%\TextAnalysisManager\

This includes:
  - Database files
  - Configuration settings
  - Backup files
  - Log files

BACKUP YOUR DATA
----------------
Regular backups are recommended. Use:
  Tools > Backup & Restore

Or manually copy your data folder listed above.

KEYBOARD SHORTCUTS
------------------
Ctrl+1    - Switch to Sources tab
Ctrl+2    - Switch to Contents tab
Ctrl+3    - Switch to Analysis tab
Ctrl+4    - Switch to All Data tab
Ctrl+5    - Switch to Timeline tab
Ctrl+6    - Switch to Reports tab
Ctrl+Q    - Exit application
Ctrl+I    - Import data
F1        - Help

TROUBLESHOOTING
---------------
If you encounter issues:

1. Check the log files in %APPDATA%\TextAnalysisManager\logs\
2. Try restarting the application
3. Ensure you have write permissions to the data folder
4. Check for Windows updates

UNINSTALLATION
--------------
To uninstall:
1. Go to Windows Settings > Apps
2. Find "Text Analysis Manager"
3. Click Uninstall

Note: You will be asked if you want to keep or remove your data.
